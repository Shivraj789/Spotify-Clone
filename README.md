# 🎵 Spotify Clone

A Spotify-inspired music streaming frontend built using HTML, CSS, and JavaScript.

## 🚀 Features

- Spotify-inspired user interface
- Music cards and playlists
- Recently Played section
- Play / Pause music
- Next / Previous song controls
- Dynamic album cover and song information
- Music progress bar
- Seek through songs
- Current song duration
- Volume control
- Automatically plays the next song

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
